EXECUTIVE RETAIL COMMAND CENTER V4
==================================

DATA SOURCE
Google Sheets (live):
https://docs.google.com/spreadsheets/d/1IWxe9kh9MJmL49C-ltIkagUNItsN0TXVAgJh2x7H2QU/edit?usp=sharing

HOW TO RUN ON WINDOWS
1. Extract this ZIP.
2. Double-click start-dashboard.bat.
3. Open http://localhost:8000 if the browser does not open automatically.
4. Keep the Google Sheet shared as “Anyone with the link – Viewer” so live sync can read it.

V4 FEATURES
- Executive sidebar navigation
- Executive Overview
- Sales Performance
- Profitability
- Customer & Team
- Supply Chain
- Full Screen / Presentation Mode
- Live Google Sheets sync every 30 seconds
- Manual Sync Now
- Open Excel Link button
- Target vs Actual + RAG indicators
- Forecasting and period comparison
- Executive alerts and recommendations
- Click Region / Category charts for transaction drill-down
- Local Excel fallback when Google Sheets cannot be reached

NOTES
- The dashboard uses CDN-hosted XLSX and ECharts libraries, so internet access is required.
- Management targets are editable benchmarks, not targets contained in the source dataset.
